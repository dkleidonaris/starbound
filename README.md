# StarBound

Official website of **StarBound**, a student aerospace research team based at the University of Thessaly in Volos, Greece.

The platform presents the team's activities, members, projects, news, and supporters through a bilingual web interface.

## Tech Stack

- **Frontend:** Nuxt, Vue.js, Tailwind CSS
- **Backend:** Laravel
- **Architecture:** REST API
- **Languages:** Greek & English

## Project Structure

The project follows a decoupled frontend/backend architecture:

- `frontend/` — Nuxt web application
- `backend/` — Laravel API

The Laravel backend provides the data consumed by the Nuxt frontend and can also support integration with external applications.
